## Milestone 1——文档导入和基础检索

状态：已完成

- 定义文档和文本块 Schema；
- 解析 PDF、Markdown 和纯文本；
- 保留页码和来源元数据；
- 实现基础向量检索；
- 提供导入和搜索接口。

完成标准：输入问题后，能够返回相关文本块和可追溯来源。

## Milestone 2——混合检索和评测

状态：进行中（检索、重排与评测程序完成；评测集扩充和质量提升未完成）

- 加入关键词检索并融合结果；
- 加入重排序；
- 创建至少 50 条人工标注的检索问题；
- 输出 Recall@5、MRR 和延迟。

完成标准：混合检索在固定评测集上优于已经记录的基础方案。

状态：已完成受约束演示工作流；文档文本块已持久化，故障历史仍为 JSON 示例

- 加入历史故障查询；
- 加入确定性的传感器摘要分析；
- 实现带工具白名单和最多三步限制的执行流程；
- 在响应中展示工具调用和证据。
